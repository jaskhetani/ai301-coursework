# plan-check

This is the installed Unit 3 skill submitted with the course repository. It
grades a proposed implementation plan and its issue comment against the issue
thread and reproduction evidence.

The authored grading components are:

- `rubric.md`: required checks and the binary verdict rule
- `procedure.md`: the ordered grading procedure
- `references/evidence-guide.md`: where each evidence family lives and what a
  passing signal looks like
- `scope.md`: the allowed Path Review repository and course house rules
- `voice-guide.md`: personal rules for upstream plan comments
